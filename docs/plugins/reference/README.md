# Core Plugin API Reference

CampusOS comes pre-packaged with 12 core plugins that provide the foundational functionality of the platform.

As a 3rd-party developer, you can list these core plugins in your `plugin.json` dependencies and interact with them via the `registry` and `eventBus`.
