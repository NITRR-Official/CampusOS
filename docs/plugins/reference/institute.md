# Institute Plugin API Reference

The `institute` plugin manages high-level organization data, such as faculties, departments, and global campus settings.

## 1. Overview

- **Plugin ID**: `institute`
- **Focus**: Global campus domains and metadata.

## 2. Permissions Exported (RBAC)

No specific club-level permissions are exposed. Institute settings are typically restricted to global super-administrators.

## 3. Services Exported

No public services are currently exposed.

## 4. Required Dependencies

None. It serves as foundational data.
