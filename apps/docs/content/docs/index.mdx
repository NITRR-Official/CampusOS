Welcome to the **CampusOS Documentation Hub**! CampusOS is an extensible, modular operating system designed for higher education campuses. It enables campus clubs, administrators, and students to manage events, budgets, equipment, room bookings, and custom workflows through an autonomous plugin ecosystem.

## Architectural Highlights

- **Decoupled Plugin Architecture**: Every feature is an isolated plugin in `/plugins/` with strict zero cross-import boundaries.
- **Dynamic Atomic RBAC**: Granular permissions declared in manifests and dynamically evaluated at the route layer.
- **Automated Database Migrations**: Sequential `up()` and `down()` migration runner with SHA-256 tamper verification.
- **Slot-Fill Micro-UI**: Next.js 16 + React 19 host runtime with per-widget `ExtensionErrorBoundary` isolation.
- **Zero-Bundle Design System**: Plugins share the `@campusos/design-system` runtime via `window.CampusOS.ui` at zero bundle overhead.
